# 가능성 예보국

초등 5-6학년 학생이 반복 실험 자료를 읽고, 가능성을 말과 0부터 1 사이의 분수로 나타내며, 새 자료를 누적해 예보와 선택을 근거 있게 유지하거나 수정하는 수학 학습 앱입니다.

## 학습 목표

- 사건이 일어날 가능성을 말로 표현하고 `0`, `1/2`, `1`과 비교합니다.
- 알려진 장치 구조에서 계산한 가능성과 자료에서 관찰한 비율을 구분합니다.
- 사건이 나타난 횟수와 전체 실험 횟수를 분수로 나타내고, 첫 자료와 새 자료를 누적합니다.
- 현재 자료를 근거로 예보를 유지하거나 수정하되, 다음 한 번의 결과를 확정하지 않습니다.
- 각 미션에 공개된 판단 규칙을 자료 비율 또는 알려진 구조의 가능성과 연결합니다.

## 앱 흐름

`개념 안내 → 실험 조건 확인 → 첫 결과 세기 → 첫 예보·임시 선택 → 새 자료 확인 → 누적 비율 계산 → 예보·선택 유지 또는 수정 → 예보 수정 기록`

안내 활동 1개와 고정 미션 5개를 제공합니다. 평가 미션에는 런타임 무작위, 점수, 순위, 자유 입력이 없습니다.

## 실행과 검증

Node.js `>=22.13.0`이 필요합니다.

```bash
npm run dev
npm run lint
npm run typecheck
npm run validate:content
npm run test:unit
npm test
npm run build
```

`npm run validate:content`는 고정 결과 배열, 누적 횟수, 말 예보, 공개 판단 규칙이 콘텐츠 계약과 맞는지 검사합니다. 브라우저·모바일·접근성 검증의 실제 실시 결과는 [검증 기록](docs/verification-log.md)에서 관리합니다.

## 자료와 개인정보

- 모든 미션 자료는 사람이 검토할 수 있는 고정 가상 자료입니다.
- 진행 상태는 React 메모리에서만 유지하며, 새로고침하면 초기화됩니다.
- 이름, 학번, 학급, 이메일, 사진, 음성, 위치, 자유 입력을 수집하지 않습니다.
- 학생 자료 업로드, 계정, 분석 도구, 광고, 영구 저장소를 사용하지 않습니다.

자세한 경계는 [개인정보 및 안전](docs/privacy-and-safety.md) 문서에서 확인하실 수 있습니다.
