# 교사용 안내

## 수업 전 확인

- 이 앱은 초등 5-6학년 개인 또는 2인 모둠 활동을 기준으로 하며, 1회 15-20분을 권장합니다.
- 앱은 고정된 가상 자료를 사용합니다. 실제 반복 실험을 대체하기보다 자료를 읽고 전후 판단을 토의하는 활동으로 활용해 주십시오.
- 진행 상태는 React 메모리에만 있으며 새로고침하면 초기화됩니다. 학생 이름, 모둠 이름, 학급 정보를 입력할 필요가 없습니다.

## 권장 수업 흐름

| 단계 | 시간 | 교사·학생 활동 |
|---|---:|---|
| 도입 | 5분 | “빨강이 5번 나왔으면 다음은 파랑일까요?”를 묻고 확정 답을 서두르지 않습니다. |
| 개념 확인 | 5분 | 알려진 장치 구조에서 계산한 가능성과 관찰 자료 비율의 차이를 안내 활동으로 확인합니다. |
| 앱 활동 | 15-20분 | 개인 또는 2인 모둠이 5개 미션에서 첫 자료, 새 자료, 누적 자료를 차례로 확인합니다. |
| 짝 설명 | 5분 | 예보를 수정한 사례와 유지한 사례를 하나씩 골라 횟수·분수·규칙으로 설명합니다. |
| 정리 | 5분 | “예보는 자료에 근거하지만 다음 결과를 보장하지 않는다”를 함께 확인합니다. |

## 활동 중 질문

- “지금 말하는 수는 장치에서 계산한 수인가요, 자료에서 나타난 비율인가요?”
- “나온 횟수만 보지 말고 무엇을 함께 보아야 하나요?”
- “새 묶음만 쓰지 않고 어떤 자료를 합쳐야 하나요?”
- “처음 예보를 바꾸거나 그대로 둘 때 각각 어떤 근거가 있나요?”
- “비율이 같고 자료량이 다르면 무엇과 무엇을 구분해야 하나요?”
- “빨강이 이어졌다는 사실이 다음 파랑을 보장하나요?”

## 관찰과 평가의 주의점

- 학생이 새 자료 뒤 예보를 바꾼 것을 첫 예보의 실패로 평가하지 마십시오.
- 누적 비율의 말 구간이 그대로이고 근거가 맞으면 예보를 유지한 학생도 동등하게 인정하십시오.
- 정답 개수, 속도, 점수보다 자료 출처 구분, 분수 표현, `1/2` 비교, 누적, 규칙 적용을 관찰하십시오.
- 앱 완료는 `[6수04-04]`부터 `[6수04-06]` 전체 성취의 유일한 증거가 아닙니다. 실제 설명, 토의, 별도 수행을 함께 보십시오.

## 실제 실험으로 확장하기

동전이나 회전판을 추가로 사용할 수 있습니다. 이때에는 매 시행이 같은 조건인지 먼저 확인하고, 모둠마다 자료가 달라질 수 있음을 비교하게 하십시오. 실제 결과가 이론값과 다르더라도 조작 실패나 부정행위로 단정하지 마십시오. 학생 이름 대신 모둠 기호를 쓰고, 결과를 성적·행동 평가나 실제 의사결정에 연결하지 마십시오.

## 안전한 사용 경계

앱의 모든 자료와 판단 규칙은 교육용 가상 상황에만 적용됩니다. 실제 날씨, 안전, 의료, 건강, 재정, 통로 선택의 판단을 대신하거나 보장하지 않습니다. 관찰 비율은 현재 자료의 요약일 뿐 정확한 가능성이나 미래 결과의 약속이 아닙니다.
