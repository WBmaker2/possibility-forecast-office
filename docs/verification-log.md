# 검증 기록

## 기록 원칙

이 문서는 실제 실시한 자동 검증과 아직 필요한 사람의 수동 검토를 구분합니다. 실행하지 않은 항목은 `미실시`로 기록하며 통과로 표시하지 않습니다. 배포는 소유자 전용 Sites 운영 주소와 로그인 경계까지 확인했습니다.

## Playwright 자동 브라우저 확인

Playwright는 `Desktop Chrome` 설정으로 실행했습니다. 이는 Safari 실제 수동 확인을 대신하지 않습니다.

| 확인 항목 | 상태 | 실제 결과 |
|---|---|---|
| 시작 화면과 프레임워크 오류 | 통과 | 학습 활동이 정상 시작되고 프레임워크 오류가 없음을 확인 |
| 관찰 자료 과장 방지 | 통과 | 관찰 자료를 확정 가능성으로 단정할 때의 교정 흐름 확인 |
| 대화상자 초점·axe | 통과 | 업데이트 내역을 닫은 뒤 초점 복귀, `axe` serious/critical 위반 0개 |
| 320px 반응형 | 통과 | 시작·개념·요약 화면에서 가로 넘침 0px |
| 전체 학습 흐름 | 통과 | 안내 활동 1개와 고정 미션 5개 전체 완주 |

## 배포 확인

Sites 소유자 전용 운영 배포가 완료되었습니다. 주소의 로그인 경계는 확인했지만, 로그인 뒤 운영 화면의 전체 학습 흐름은 아직 별도 확인이 필요합니다.

| 항목 | 필요한 확인 | 상태 | 날짜 | 주소·결과 |
|---|---|---|---|---|
| 운영 주소 | 직접 접속 시 정상 응답 | 통과 | 2026-07-17 | [가능성 예보국](https://possibility-forecast-office.wbmaker.chatgpt.site), 소유자 전용 로그인 화면 응답 확인 |
| 정적 자원 | 로그인 뒤 직접 경로와 새로고침 뒤 자원 경로 정상 | 필요·미실시 | 미정 | 소유자 로그인 뒤 확인 필요 |
| 운영 화면 | 로그인 뒤 업데이트 내역, 개인정보 안내, 안내 활동과 미션 5개 흐름 확인 | 필요·미실시 | 미정 | 로컬 전체 E2E는 통과했으나 운영 로그인 뒤 수동 확인 필요 |

## 변경 이력 추가 규칙

결과 자료, 수학 설명, 판단 규칙이 바뀌면 콘텐츠 버전, 독립 검수일, 자동 검증 결과, 브라우저 확인 결과를 함께 갱신합니다. 접근성·모바일·문구 개선도 앱의 업데이트 내역과 이 문서에 각각 기록합니다.
