# 개인정보 및 안전

## 개인정보 비수집 계약

이 앱은 다음 정보를 수집하거나 입력받지 않습니다.

- 이름, 학번, 학급, 학교, 이메일, 계정 정보
- 사진, 음성, 위치, 연락처
- 자유 텍스트, 실제 실험 결과, 학생 성적·출결·행동 자료
- CSV·파일 업로드, 붙여 넣기, 학급 투표나 설문 응답

모든 미션은 가상 장치의 고정 결과 자료를 사용하며, 실제 학생·학교·지역을 나타내지 않습니다.

## 저장과 네트워크

- 학습 진행 상태는 React 메모리에서만 유지합니다.
- `localStorage`, `sessionStorage`, IndexedDB, 쿠키를 학습 기록 저장에 사용하지 않습니다.
- 새로고침하면 진행 기록이 초기화됩니다.
- 계정, 교사 대시보드, 클라우드 저장, 학생 분석 로그를 제공하지 않습니다.
- 분석 도구, 광고, 추적 픽셀, 외부 폰트, 외부 CDN, 원격 이미지 요청을 사용하지 않는 것을 목표로 합니다.
- 앱 시작 후에는 초기 정적 자원을 제외한 네트워크 요청이 없어야 합니다. 이 항목의 실제 브라우저 확인 결과는 [검증 기록](verification-log.md)에 남깁니다.

## 학습 안전 경계

- 앱은 실제 날씨, 재난, 건강, 안전, 의료, 재정, 투자, 보험, 도박, 복권, 스포츠 결과를 예측하거나 판단하지 않습니다.
- 관찰 비율은 현재 자료의 요약이며, 정확한 가능성이나 다음 결과의 보장이 아닙니다.
- 미션의 판단 규칙은 가상 상황에 한정됩니다. 실제 통로·안전·건강 등과 관련된 결정을 대신하지 않습니다.
- “연속 결과 뒤에는 반대 결과가 나올 차례”라는 설명을 사용하지 않습니다.

## 운영 시 유의사항

교사는 학생이 앱 화면이나 결과를 외부에 공유하도록 요구하지 않아야 합니다. 실제 수업 실험을 덧붙일 때에도 학생 이름 대신 모둠 기호를 사용하고, 결과를 성적·행동 평가나 실제 의사결정에 연결하지 않아야 합니다. 오류 화면에는 내부 스택이나 사용자 환경 정보를 노출하지 않는 것을 원칙으로 합니다.
